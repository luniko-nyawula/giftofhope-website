# Gift of Hope Foundation Website

## Project Overview

The **Gift of Hope Foundation Website** is a responsive website created for the Gift of Hope Foundation, a South African non-profit organisation that supports vulnerable children, unemployed youth, and disadvantaged families.

The purpose of the website is to create a central online platform where visitors can learn more about the organisation, view its programmes, become volunteers or sponsors, and contact the foundation.

The website is designed to improve the organisation's online presence and communication with community members, volunteers, sponsors, and donors.

## Mission

The Gift of Hope Foundation aims to improve the lives of vulnerable communities by providing practical support, education, and development opportunities.

## Vision

The organisation aims to build stronger communities where everyone has access to opportunities that improve their quality of life.

## Target Audience

The website is aimed at:

* Community members
* Beneficiaries
* Volunteers
* Sponsors
* Donors

## Website Objectives

The main objectives of the website are to:

* Increase awareness of the Gift of Hope Foundation.
* Provide information about the organisation and its programmes.
* Recruit new volunteers.
* Encourage individuals and businesses to become sponsors.
* Improve communication with the public.
* Provide an online enquiry platform.

## Website Pages

The website consists of five main pages:

### 1. Home

**File:** `index.html`

The home page introduces visitors to the Gift of Hope Foundation.

It includes:

* Introduction to the organisation
* Navigation menu
* Featured programmes
* Call-to-action buttons
* Links to other sections of the website

### 2. About Us

**File:** `about.html`

This page provides information about the organisation.

It includes:

* Organisation history
* Mission
* Vision
* Values
* General organisational information

### 3. Services

**File:** `services.html`

This page provides information about the programmes and services offered by the foundation.

These include:

* Educational support
* Food assistance
* Youth development
* Community outreach programmes

### 4. Enquiry

**File:** `enquiry.html`

The enquiry page allows visitors to contact the organisation about volunteering or sponsorship.

The form includes:

* Full name
* Email address
* Cellphone number
* Enquiry type
* Message

Visitors can use the form to enquire about becoming a volunteer or sponsor.

### 5. Contact

**File:** `contact.html`

The contact page provides ways for visitors to communicate with the organisation.

It includes:

* Contact information
* Operating hours
* Email address
* Telephone number
* Physical locations

The proposed locations include:

* Main Centre – Durban
* Community Hub – Pietermaritzburg

## Design

The website uses a clean and professional design that is intended to work on both desktop and mobile devices.

### Colour Palette

| Colour     | Hex Code  | Purpose                             |
| ---------- | --------- | ----------------------------------- |
| Dark Blue  | `#1F4E79` | Trust and professionalism           |
| Green      | `#2E8B57` | Growth and community                |
| White      | `#FFFFFF` | Readability                         |
| Light Grey | `#F4F4F4` | Background sections                 |
| Orange     | `#F49C12` | Buttons and call-to-action elements |

### Typography

The proposed typography is:

* **Headings:** Calibri Bold
* **Body text:** Calibri Regular

The website also uses responsive layouts, consistent navigation, readable fonts, and accessible colour contrast.

## Technologies Used

The project is developed using:

* **HTML5** – Used to create the structure and content of the website.
* **CSS3** – Used for styling, colours, layouts, and responsive design.
* **JavaScript** – Used to add functionality and interactivity.
* **GitHub Pages** – Used to host the completed website.

## How to Run the Website

### Option 1: Open Locally

1. Download or clone the project.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your web browser.
5. Use the navigation menu to access the different pages.

### Option 2: Using VS Code

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Use a browser or Live Server extension to view the website.
4. Make changes to the HTML, CSS, or JavaScript files as required.

## Hosting

The proposed website will be hosted using **GitHub Pages**. GitHub Pages is used because it provides free hosting and can be used to keep track of the project.

## Current Website Situation

The foundation currently communicates mainly through social media and community events. These platforms allow the organisation to share updates but do not provide one central location for all of its information.

The proposed website addresses this by providing one platform where visitors can:

* Learn about the organisation.
* View its programmes.
* Make enquiries.
* Find contact information.
* Enquire about volunteering.
* Enquire about sponsorship.

## Strengths

The project builds on the foundation's existing strengths, including:

* Social media presence
* Community engagement
* Regular programme updates

## Problems Addressed

The website aims to address the following weaknesses:

* No dedicated website
* No online volunteer registration
* No online sponsorship enquiry system
* No central source of organisational information
